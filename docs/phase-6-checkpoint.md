# Phase 6 checkpoint: assets and documents

The explicit `[assets]` configuration selects a private root and database. Omitted or `not_configured` assets fail closed. Startup does not create storage. Source bytes are SHA-256 addressed and deduplicated. A document stores provenance to its original asset, text origin, deterministic pages, and stable page/section chunks. Search is lexical and bounded; Gateway text results redact absolute local paths.

The asset's MIME field preserves the first validated declaration even when identical bytes are later registered under another allowed type; the document records the type used to ingest it. Path redaction includes `//server/share/...` UNC paths in public metadata and text.

`text/plain` ingestion decodes UTF-8 and splits pages on form-feed characters. PDF ingestion parses bytes locally with `pypdf`, preserves page order, and normalizes indirect font metric/encoding members in memory. A single empty user password is tried on encrypted PDFs; a non-empty protected file is rejected without password guessing. Deterministic Unicode sanity checks mark malformed ToUnicode output `pdf_text_layer_suspicious`, keep the raw PDF, and prevent that page from entering the text index. PDFs are bounded to 64 MiB, 999 pages, 1 MB per decoded page/Form stream, 4 MB per decoded font/CMap stream, and 32 MB total decoded stream data. Projected repeated Form XObject expansion has a separate 32 MB budget; page text, font/resource traversal and XForm invocation count have further caps. Large local PDFs use the optional MCP `ingest_document_file` tool, enabled only by an explicit `[assets].ingest_root`; the caller supplies a relative path and the Gateway rejects paths outside that root. Inline byte ingestion and non-PDF asset limits remain small. OCR is按需且有界：初次 ingestion 最多 8 页、单批最多 16 次尝试；剩余 suspicious/unavailable/failed 页面由候选工具暴露，后续每次最多 16 页。`pdf_text_layer` 的 public status 是 `unverified`，不代表视觉完整；原始 PDF 页面是权威视觉来源。空 OCR 标记为 `pdf_ocr_empty` 且不建索引，失败状态保持可重试。OCR 只提供确定性 derived text，不做语义解释。

The MCP server exposes typed document tools; `ingest_document_file` is discovered only when the private source root is explicitly configured and requires the `ingest` capability. Tests use generated synthetic PDFs, text and scan-like pages, and both in-process and independent stdio MCP clients. Run `uv run --extra dev pytest -q` for the full suite.

## Verification and external capability gate

- Phase 6 targeted/MCP regression: `87 passed, 1 skipped`. Full repository regression: `280 passed, 5 skipped`. Detailed real-copy evidence is recorded in [`phase-6-closeout.md`](phase-6-closeout.md).
- Synthetic tests cover valid multi-page and 269-page text-layer extraction, empty-password encryption versus genuinely password-protected PDFs, indirect font metrics/encoding members, malformed PDFs, cyclic indirect/resource references, oversized compressed streams, aggregate decoded-stream bounds, inherited page/Form resources, repeated Form invocations, nested same-name Form/image scopes, OCR fallback provenance/unavailable marking, blank OCR output, stable identities, search/fetch, and per-PDF/per-batch OCR bounds.
- A disposable real-copy MCP smoke with OCR explicitly disabled verified 269 page mapping, 40 `pdf_text_layer`, 3 `pdf_ocr_unavailable`, 226 suspicious pages, search/page/image resource provenance, and duplicate-source reuse. A separate controlled OCR continuation stopped after four complete 16-page batches at 40 `pdf_text_layer`, 72 `pdf_ocr_derived`, 157 suspicious pages, and 118 chunks; full-book eager OCR is not a Phase 6 condition. The bundled engine emits non-fatal “Parameter not found” warnings for some traineddata settings; OCR remains text extraction, not an equation-recognition guarantee.
- `text_layer_status=unverified` means only that deterministic Unicode sanity checks found no explicit corruption markers. It is not a visual-completeness guarantee: formula fidelity requires Agent verification against the original page image.
- PyMuPDF is an optional OCR dependency. Its upstream project offers AGPL and commercial licensing; Phase 10 must review license obligations before distributing an installation that includes the `pdf-ocr` extra.
- PDF decompression is constrained with pypdf's scoped stream/output/page-tree/XObject limits plus aggregate stream and repeated-Form budgets; reference and resource cycles are rejected. Large file ingestion is restricted to an explicit source root; it does not expand base64 or arbitrary path access.
