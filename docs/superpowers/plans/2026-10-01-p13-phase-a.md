# P13 Phase A Implementation Plan

> **For agentic workers:** 使用 executing-plans 在当前独立 worktree 顺序实施。
> 用户要求阶段顺序；不委派其它阶段、不提前规范化。

**Goal:** 建立完整、可重跑、Git 外的历史来源 inventory 与 migration ledger。

**Architecture:** 显式 acquisition descriptors 经已有 verified file reader 获取内容指纹；
有界 metadata probe 只判断源结构。独立 ledger 保存每次获取位置及状态事件，公开输出
只有聚合统计。V2 数据读取/写入仍只通过正式 Gateway。

**Tech Stack:** Python 3.11、stdlib、SQLite、pytest，复用 migration 路径/文件安全校验。

## Global Constraints

- 数据不丢失 > provenance 正确 > 可恢复 > normalization 数量 > 清理旧系统。
- 真数据、日志、回执、配置、archive、ledger 全在 Git 外；fixture 完全 synthetic。
- 不扫描无关磁盘/credential stores；未知角色/边界/时间不猜。
- source-only Gate 通过前不进行 canonical schema 设计或 normalization。
- imported/reused 必须来自真实 Gateway 工具回执，不能从 ledger 推断 V2 现状。
- 不 bump 版本、不发布未通过真实 Gate 的 P13、不删除 V1。
