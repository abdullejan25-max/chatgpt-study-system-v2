# Phase 4–9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolve the read-only local Study Gateway into deterministic, agent-agnostic MCP infrastructure for History, documents/assets, wrong answers, and safe writes.

**Architecture:** Keep all domain operations on a transport-neutral `Gateway`; stdio MCP validates and maps protocol messages only. A private SQLite store owns History, Asset, Document, WrongAnswer, idempotency, and audit metadata; blobs live only under explicit asset roots and are addressed with logical URIs. No model provider or inference runtime is introduced.

**Tech Stack:** Python 3.11, stdlib SQLite/FTS5, stdlib hashing/path APIs, existing MCP SDK, optional local PDF/OCR adapters with deterministic fallback.

## Global Constraints

- Agent thinks; Gateway executes; the Gateway has no LLM/VLM or model-provider dependency.
- All configured filesystem roots must be explicit and fail closed when absent.
- Public MCP values use logical IDs/URIs and safe errors, never private absolute paths.
- Tests use synthetic data only and verify real MCP stdio protocol boundaries.
- No Tunnel, Responses API, remote deployment, Git remote, push, or publish work is in scope.
