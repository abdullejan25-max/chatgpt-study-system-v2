- `study_system` 提供 Study、History/Sources、active Wrong Answers 及有界 Asset/Document logical-reference 读取。Study/source/Wrong Answer 三类 no-result 查询如实报告无结果。166 sources 与 canonical messages=0 保持既定 source-only 边界；不伪造 normalized conversation、author 或 role。
- 项目规则明确所有 V2 读取、计数、存在性判断和持久化写入都经过 Gateway。WorkBuddy 不直接访问 private SQLite/store，不维护第二套 Study/Memory，不复制领域逻辑；Basic Memory 保持 disabled。
- Controlled-write 在独立私有 target 完成 canonical workflow、v1 read-back、expected_version 更新至 v2、幂等重试和 stale-version conflict。真实完全退出/重启后的 exact timestamp/provenance 对比通过；无 v3，未污染 production。

- 新增显式 `collect_wrong_answer_projection`，复用 projection capability、水位分页与完整性校验，支持未配置 History 的隔离目标。省略的 domain 不被宣称为空；默认 collector 仍对 unavailable backend 报错。
- 正式 Gateway → collector → renderer → manifest-owned writer 在独立 Vault 生成 14 个 Markdown，latest v2、v2→v1 supersession、Document URI、空 Study relations 与 provenance 正确。两次 manifest 和全部 Markdown byte-identical，无重复、随机 ID 漂移、原始 Asset bytes 或绝对私人路径。不访问或修改真实 StudyVault，不生成假 Study links。
- 将 `.workbuddy/` 加入公开 `.gitignore`，修复仅靠 Git local exclude 时 sdist 可能包含本地 WorkBuddy 配置/日志的问题。含私人文件的失败构建仅在本机，未发布；正式 wheel/sdist 单独审计。

## Compatibility and limits

WorkBuddy Desktop 5.6.2 的同名 MCP definition 优先级/reload 保证未建立；托管 production `study_system` 保留，使用独立临时 `study_system_p12_isolated` 做可跨重启的隔离验收。该问题是 Host config persistence / resolution precedence，不是 Gateway 数据丢失。标准 MCP 已足够，无 WorkBuddy-specific 业务 adapter。

原有 Codex Host `resources/list` 的 `Unexpected response type` 继续 deferred / non-blocking；fresh official MCP stdio 正常。长期存活的 Host 进程需 reconnect 才加载新安装版本。package、MCP server metadata 及本地 Gateway version 配置同步为 `0.4.0`；历史真实 Host Gate 的 `0.3.0` health 是验收基线。

Hermes、Cross-Agent 最终阶段、WorkBuddy 历史迁移、ChatGPT/Gemini import、canonical normalization、V1 删除及 Obsidian 重设计不在此发布范围。隔离 Projection 的人工外观观察是可选项，没有重开已 PASS 的 Step 1 GUI Gate。Projection 不是 authoritative store；各 store 独立水位与 writer 非 crash-atomic 的既有限制保留。

私有 MCP/Gateway 配置、聊天、日志、DB、StudyVault、原始图像/PDF、导出、credentials/tokens 和隔离运行数据均不进入 Git 或 release packages。项目保持 Apache-2.0；PyMuPDF 仍仅在 `pdf-ocr` extra，使用自身许可证。
