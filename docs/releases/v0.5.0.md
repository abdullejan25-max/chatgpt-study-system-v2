## Verified behavior

- 真实 CLI Agent 读取 canonical workflow，生产只读 Study/source/Wrong Answer 检索与
  bundle/version 回读；source 128 bytes、原始 Asset 64 bytes 有界读取。
  三类唯一不存在查询如实无结果，没有 general knowledge 补用户记录。
- 官方 Host session export trace 证明只调用 Gateway；没有 shell/filesystem/SQL/Memory
  或 session_search 补数。source-only 档案与 canonical messages 语义保持独立。
- 独立 `study_system_p12_hermes_isolated` 保存显式 SYNTHETIC ONLY document/source，
  创建 v1/v2；完整相同 request/key replay 返回相同 v2，新 key/stale version 返回
  CONFLICT，final bundle total=2，无 v3。生产 server/config 未被同名隔离目标覆盖。
- Gateway 生成时间、逻辑引用、provenance IDs 与 supersession；caller identity 始终
  reported/unverified。Hermes Memory/profile disabled；必要 session metadata 不作为 V2 权威层。
- 真实 CLI Host 退出后新进程经 Gateway 找回实际 ID，document/page/full bundle 与
  退出前工具回执 exact-equal。首轮 Agent 抄错 ID 的 INVALID_ARGUMENT 不计 PASS；
  后续通过检索实际 ID 纠正，不改 Gateway 或读取 store。
- 正式 isolated MCP → scoped collector → renderer → manifest-owned writer，两次
  14 个 Markdown 与 manifest byte-identical；latest=v2、supersession、document ref、
  空 Study relations 与 provenance 摘要正确。无重复页面、绝对私人路径或 raw Asset bytes。
- `.hermes/` 公共排除防止 Host config/session/memory/log/credential 入 Git 或包，
  五个针对性测试先失败再通过。发布前审计 tree/staged/untracked、wheel/sdist 和
  v0.4.0 之后新增 reachable Git objects；不只依赖 `.gitignore`。
