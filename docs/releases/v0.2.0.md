# v0.2.0 — Legacy Migration

V1 legacy source migration and V2 cutover passed the P11 gate. Original data and V1 remain preserved; no deletion was performed.

- Study and its 511 documents reuse the existing authoritative root in place.
- 55 legacy chat documents, 28 wrong-answer documents and 1 derived fact migrated as exact, typed source artifacts, with stable IDs, original byte hashes, known source time and separate import provenance.
- Codex snapshot identity is verified using the correct snapshot/manifest digest meanings. 82 original JSONL source documents are preserved and retrievable. They are not reported as normalized conversations/messages.
- 70 original images passed byte read-back: 66 new Assets and 4 content duplicates reused. Existing native provenance was preserved.
- 97 explicit note-to-image references were retained. Complete Wrong Answer semantics remain unresolved for 28 notes; the active 5 sources/5 analyses were unchanged. No invented questions, answers, analyses or versions were created.
- Restricted internal source/Asset apply services validate explicit source sets, use domain transactions, create verified DB/WAL/blob snapshots, prove isolated restores and checkpoint durable read-backs. They are not Agent-facing import tools.
- Same-source real reruns produced zero new items and retained stable IDs/import times. Counts reconcile: 1,209 V1 items = 150 imported + 1,052 reused + 7 skipped. The 82 Codex source documents are a separate extension.
- New read-only MCP source listing, literal search and bounded original-byte retrieval passed real fresh-process E2E, cross-source/no-result checks and restart persistence.
- Final default/dev verification passed 605 tests with 12 documented platform/optional skips. The source distribution and wheel build, package resource checks and public-history/package privacy audits passed; PyMuPDF remains optional.
- V2 stores are selected in the private project configuration; V1 runtime/code is retired for this project. A deletion candidate report classifies preserved archives and authoritative data without authorizing deletion.

Known limitations: canonical conversation/message/attachment normalization remains deferred; source search is literal and case-sensitive. ChatGPT and Gemini official exports remain WAITING_FOR_USER and are later external History expansion, not completed V1 migration items. Hermes and WorkBuddy source/client expansion remains deferred. Existing long-running MCP clients must reconnect to load the current configuration and new tools; the initiating Codex connection still held its earlier configuration during validation. P12 preparation is retained without further product expansion.

See [P11 real migration evidence](https://github.com/abdullejan25-max/cognivault/blob/v0.2.0/docs/p11-real-migration-completion.md) and [V1 deletion candidates](https://github.com/abdullejan25-max/cognivault/blob/v0.2.0/docs/v1-deletion-candidates.md) for aggregate evidence, scope and limitations. Private configuration, databases, journals, raw files, screenshots, source identifiers and recovery receipts are excluded from this release.
