## Compatibility and limits

Fresh official MCP stdio initialization, resources/list, canonical workflow read, tools discovery and real projection work. The existing Codex Host resources/list compatibility issue is independently deferred under the agreed rule; it was not repaired or expanded into protocol refactoring. New processes report Gateway `0.3.0`, `health_report.ok=true` and History `sqlite/ready`. Long-lived Host processes may need reconnecting to load the installed version and projection permission.

Source views are metadata-only. Stores have independent watermarks rather than a global atomic snapshot. The writer recovers handled failures but does not guarantee crash-atomic directory replacement. External-agent integration, ChatGPT/Gemini import, canonical conversation/message normalization, V1 deletion and incremental redesign remain deferred.

Private Vault content, configuration, images, databases, raw exports, source IDs and absolute private paths are excluded from Git and release packages. Project license remains Apache-2.0; optional PyMuPDF retains its separate licensing and remains confined to the `pdf-ocr` extra.

See [P12 evidence and all Gate items](https://github.com/abdullejan25-max/cognivault/blob/v0.3.0/docs/p12-step1-real-projection-checkpoint.md).
