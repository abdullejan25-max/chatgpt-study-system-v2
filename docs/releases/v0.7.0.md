# v0.7.0 — History Completion & Recovery

Historical inputs now enter immutable source evidence before deterministic
conversation normalization. Reliable roles, ordering and boundaries produce
canonical conversations/messages; ambiguous and unsupported inputs retain their
original source-only representation. Gateway executes transformations and data
operations; Agent reasoning remains outside the data layer.

- Private acquired-data reconciliation validates 1,802 logical sources/outcomes,
  487 conversations, 7,334 distinct messages and 494 source-specific views.
  1,349 sources remain wholly source-only. Exact/derived-safe message appearances
  are 5,468/2,024; 237 ambiguous candidates produce no guessed messages.
- Source-only adapters preserve historical Codex, WorkBuddy, Hermes, Gemini,
  Basic Memory and V1 evidence. ChatGPT branching/tree support is tested with
  invented fixtures; its real export remains acquisition_pending for incremental,
  idempotent acquisition. Existing imported sources are not rebuilt.
- Late V1 audit captures 26 additional files, exact rerun reuses all 26 and adds
  zero canonical messages. Every one of 442 bounded original V1 inputs has an
  evidence mapping; V1-only unknown = 0. Existing P11 accounting is reused.
- Native full backup/isolated restore validates 3,778 files / 44,380,473,111 bytes,
  including Study/QMD and every configured data domain. A verified 237-file /
  1,048,793,838-byte mutable supplement protects the late acquisitions without
  another static Study copy. It explicitly excludes Study and accompanies the
  original full backup. Manifests, whole logical digests, source identities,
  provenance and migration ledger reconcile through the Gateway.
- Recovery handles committed WAL, streaming BLOB checksums, Windows long paths,
  strict component/path validation, immutable catalog anchors and isolated targets.
  Capacity includes copy, temp/WAL and reserve. Long native recovery leaves MCP
  ping responsive. Existing snapshots/configurations remain compatible.
- The V1 router has no active runtime/scheduled dependency; its Basic Memory
  writer hooks are disabled with reversible configuration backups. Raw DBs,
  sources and cold archives remain retained. Physical deletion requires the
  owner's separate, explicit confirmation.
- Persistent production writable ingress preserves a separate P13 readonly
  profile and the P12 isolated aliases. A marked, entirely invented Wrong Answer
  passes native Asset/source/v1/v2, exact replay, stale CONFLICT, original-byte,
  version-chain/provenance and fresh Hermes readback. The marked synthetic source
  and two versions are retained because no formal deletion API exists.
- Codex Desktop and Hermes native History readback remain PASS. WorkBuddy P13
  History GUI verification is DEFERRED due to external capture/input automation;
  prior P12 integration PASS remains valid. Persistent WorkBuddy writable config
  is not misrepresented as a new Desktop GUI write PASS.

## Validation and privacy

Targeted: 380 passed / 1 existing skip. Full: 828 passed / 12 existing skips.
Version/transport checks: 38 passed / 1 existing skip. Recovery: 53 passed.
Clean installed-wheel synthetic permissions/recovery/idempotency checks: 9 passed.
Wheel/sdist, diff and public working/staged/package/intended-ancestry privacy
audits pass. Public commit/tag and actual remote/fresh-clone verification are
recorded with the release. No new unexpected skip is accepted as a passing test.

Only generic engineering, invented fixtures and sanitized aggregate documentation
are public. Real exports, conversations, raw identifiers, paths, credentials,
runtime configs, ledgers, receipts, source archives and backups remain local.
Local private Codex refs are neither rewritten nor pushed.

## Upgrade and limits

Back up through the configured Gateway, install the frozen non-editable release,
align private Gateway version and reload the Host. Keep data bindings and the
private readonly profile. Recovery is opt-in admin-only; daily production ingress
uses read/ingest/write without recovery or projection privileges.

StudyVault stays authoritative. Normalization never overwrites source evidence,
guesses missing time/role/model identity or flattens a branching conversation.
Missing attachments remain explicit; Gemini's opaque export members remain
preserved without invented Asset refs. Legacy Wrong Answer documents retain the
accepted semantic-reconstruction limitation. Caller identity is still reported /
unverified, not authentication. Cloud sync, vectors and new authentication are
outside this release.
