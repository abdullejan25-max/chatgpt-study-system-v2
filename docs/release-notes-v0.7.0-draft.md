# Draft — History Completion & Normalization

This is release preparation, not a published version or a completed P13 Gate.
The current package version remains 0.6.0. Consult the P13 checkpoint for actual
local-data execution and remaining Host/recovery/retirement evidence.

- Private inventory/ledger and idempotent source-only ingestion preserve original
  evidence, provenance and exact-duplicate mappings.
- Deterministic adapters support six historical source categories. Reliable
  roles/order/boundaries produce canonical conversations/messages; uncertain and
  unsupported material remains source-only. ChatGPT trees preserve branch views.
- Canonical identity, confidence, timestamp semantics, ordering, attachments and
  source-specific provenance remain separate from immutable original evidence.
- Incremental ingestion and repeated normalization reuse deterministic identities.
- Native Gateway read/search/verification and configured private snapshot/restore
  tools preserve the shared data boundary.
- Public tests use invented fixtures only. Real exports, stores, transcripts,
  ledgers, receipts, configs and backups remain local and outside Git/package.

Publication and V1 retirement require their separate acceptance Gates. Physical
deletion always requires explicit owner confirmation; retaining a cold archive
is an accepted outcome.
